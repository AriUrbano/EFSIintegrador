Descripcion:
Presupuesto Boca Juniors es una aplicación web para gestión de finanzas personales desarrollada en React, con diseño inspirado en los colores del Club Atlético Boca Juniors. Permite a los usuarios registrar, editar, eliminar y categorizar sus ingresos y gastos de manera intuitiva.
Características Principales:
Gestión completa de movimientos financieros
Filtros avanzados por categoría, tipo, fecha y monto
Interfaz responsive adaptada a todos los dispositivos
Modo oscuro/claro con persistencia de preferencias
Almacenamiento local sin necesidad de backend
Cálculos automáticos de balances y totales
Validación de formularios en tiempo real
Instrucciones:
npm i
npm run dev
